# Upscalo Models

On-device AI model files for the **Upscalo** iOS app. The app downloads them when the user
chooses to, checks each file against `SHA256SUMS.txt`, and runs them entirely on the iPhone —
photos never leave the device. There is nothing to install manually.

| File | Size |
|---|---|
| `enhancer-p2.zip` | 14.6 MB |
| `enhancer-f.zip` | 83.6 MB |
| `enhancer-b.zip` | 16.2 MB |
| `enhancer-n.zip` | 27.7 MB |

Each archive contains a compiled Core ML model (`.mlmodelc`).
